Política de Privacidade do CifrasCCB

Esta Política de Privacidade descreve como o aplicativo CifrasCCB, publicado por FCore Apps, trata informações dos usuários.

Última atualização: 17 de maio de 2026

1. Quem somos

O CifrasCCB é um aplicativo voltado à exibição de cifras musicais. Este aplicativo é publicado por FCore Apps.

2. Coleta de dados

O CifrasCCB foi desenvolvido para funcionar de forma simples e com o mínimo possível de tratamento de dados.

Resumo: o aplicativo não exige criação de conta, não possui login e não realiza rastreamento de usuários para fins de perfil, marketing ou publicidade.

Atualmente, o aplicativo:

  • não solicita cadastro de usuário;
  • não exige login;
  • não coleta dados pessoais como nome, e-mail, telefone ou documento;
  • não vende dados dos usuários;
  • não compartilha dados pessoais com anunciantes;
  • não exibe publicidade;
  • não utiliza os dados do usuário para anúncios comportamentais.

3. Informações armazenadas localmente no dispositivo

Para permitir o funcionamento de recursos do app, algumas preferências podem ser armazenadas localmente no dispositivo, como por exemplo:

  • configurações de visualização;
  • preferências de uso;
  • itens marcados como favoritos.

Essas informações ficam, em regra, no próprio aparelho do usuário e são utilizadas apenas para o funcionamento do aplicativo.

4. Compartilhamento de dados

O CifrasCCB não compartilha dados pessoais dos usuários com terceiros, exceto quando isso for estritamente necessário para o funcionamento técnico do aplicativo ou quando houver obrigação legal.

5. Serviços e conteúdo de terceiros

O aplicativo pode utilizar recursos técnicos de terceiros apenas para viabilizar seu funcionamento, como hospedagem de arquivos ou distribuição de conteúdo estático.

Caso algum serviço de terceiros processe dados técnicos indispensáveis ao funcionamento da conexão, esse tratamento ocorrerá de acordo com as políticas e práticas do respectivo fornecedor.

6. Publicidade

O CifrasCCB não exibe anúncios e não utiliza SDK de publicidade no contexto desta política.

7. Crianças e adolescentes

O aplicativo pode ser utilizado por pessoas de todas as idades. O CifrasCCB não é projetado para coletar dados pessoais de crianças.

8. Segurança

Buscamos adotar medidas razoáveis para manter o aplicativo seguro e reduzir a exposição desnecessária de dados. Ainda assim, nenhum sistema é completamente imune a falhas ou riscos.

9. Retenção e exclusão de dados

Como regra, o CifrasCCB não mantém base própria de dados pessoais de usuários.

Preferências armazenadas localmente no dispositivo podem permanecer salvas até que o usuário:

  • as remova dentro do próprio aplicativo, se essa opção estiver disponível;
  • limpe os dados do app no sistema operacional; ou
  • desinstale o aplicativo.

10. Direitos e contato

Em caso de dúvidas sobre esta Política de Privacidade, entre em contato pelo e-mail:

fcoreapps@gmail.com

11. Alterações nesta política

Esta Política de Privacidade pode ser atualizada periodicamente para refletir melhorias no aplicativo, mudanças legais ou ajustes técnicos.

Recomendamos que o usuário revise esta página ocasionalmente para verificar a versão mais recente.

12. Consentimento

Ao utilizar o CifrasCCB, o usuário declara estar ciente desta Política de Privacidade.
